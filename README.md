Aqui está o texto completo em um único bloco, sem seções ou formatações separadas:Guia Prático de Testes de API REST — Gestão de Veículos. Este guia contém a resolução de exercícios práticos para manipulação de uma API REST rodando em http://localhost:3000/api/v1/veiculos. Antes de começar, certifique-se de ter instalados as ferramentas curl, httpie e jq no seu sistema. Para o Exercício 01, efetue uma requisição GET buscando o veículo de ID 1 e formatando a saída com jq usando o comando: curl -s -X GET http://localhost:3000/api/v1/veiculos/1 | jq . (ou via HTTPie: http GET http://localhost:3000/api/v1/veiculos/1). Para o Exercício 02, cadastre um novo caminhão com a montadora Volvo, modelo FH 540, placa KLL-9090 e verifique se o retorno é HTTP 201 Created com o comando: curl -i -X POST http://localhost:3000/api/v1/veiculos -H "Content-Type: application/json" -d '{"montadora": "Volvo", "modelo": "FH 540", "placa": "KLL-9090", "status": "DISPONIVEL"}' (ou via HTTPie: http POST http://localhost:3000/api/v1/veiculos montadora="Volvo" modelo="FH 540" placa="KLL-9090" status="DISPONIVEL"). Para o Exercício 03, tente cadastrar um veículo sem a propriedade placa para validar o retorno 400 Bad Request executando: curl -i -X POST http://localhost:3000/api/v1/veiculos -H "Content-Type: application/json" -d '{"montadora": "Volvo", "modelo": "FH 540"}' (ou via HTTPie: http POST http://localhost:3000/api/v1/veiculos montadora="Volvo" modelo="FH 540"). Para o Exercício 04, filtre os veículos com o status DISPONIVEL utilizando query params através do comando: curl -s -X GET "http://localhost:3000/api/v1/veiculos?status=DISPONIVEL" | jq . (ou via HTTPie: http GET http://localhost:3000/api/v1/veiculos statusDISPONIVEL). Para o Exercício 05, atualize o status do veículo de ID 3 para EM_ROTA com a rota PATCH executando: curl -i -X PATCH http://localhost:3000/api/v1/veiculos/3 -H "Content-Type: application/json" -d '{"status": "EM_ROTA"}' (ou via HTTPie: http PATCH http://localhost:3000/api/v1/veiculos/3 status="EM_ROTA"). Para o Exercício 06, valide a resposta 404 Not Found tentando alterar ou remover um ID inexistente como o ID 99 com os comandos: curl -i -X PATCH http://localhost:3000/api/v1/veiculos/99 -H "Content-Type: application/json" -d '{"status": "EM_ROTA"}' ou curl -i -X DELETE http://localhost:3000/api/v1/veiculos/99. Para o Exercício 07, adicione no código da sua API Express a rota PUT em /api/v1/veiculos/:id validando todos os campos com a seguinte lógica: app.put('/api/v1/veiculos/:id', (req, res) => { const { id } = req.params; const { montadora, modelo, placa, status } = req.body; if (!montadora || !modelo || !placa || !status) return res.status(400).json({ error: 'Todos os campos são obrigatórios' }); const index = veiculos.findIndex(v => v.id === parseInt(id)); if (index === -1) return res.status(404).json({ error: 'Veículo não encontrado' }); veiculos[index] = { id: parseInt(id), montadora, modelo, placa, status }; return res.status(200).json(veiculos[index]); }); e teste a rota com o comando: curl -i -X PUT http://localhost:3000/api/v1/veiculos/1 -H "Content-Type: application/json" -d '{"montadora": "Scania", "modelo": "R 450", "placa": "ABC-1234", "status": "DISPONIVEL"}'. Para o Exercício 08, crie o arquivo teste_crud.sh com o código em Bash a seguir para automatizar os testes e gerar os logs em crud_result.log: #!/bin/bash LOG="crud_result.log"; URL="http://localhost:3000/api/v1/veiculos"; echo "= INICIO =" > $LOG; R1=$(curl -s -X POST$URL -H "Content-Type: application/json" -d '{"montadora": "Volvo", "modelo": "FH 540", "placa": "AAA-1111", "status": "DISPONIVEL"}'); ID1=$(echo$R1 | jq -r '.id'); echo "Cadastrado ID: $ID1" >> $LOG; R2=$(curl -s -X POST$URL -H "Content-Type: application/json" -d '{"montadora": "Scania", "modelo": "R 450", "placa": "BBB-2222", "status": "DISPONIVEL"}'); ID2=$(echo$R2 | jq -r '.id'); echo "Cadastrado ID: $ID2" >> $LOG; curl -s -X PATCH "$URL/$ID1" -H "Content-Type: application/json" -d '{"status": "EM_ROTA"}' >> $LOG; curl -s -i -X DELETE "$URL/$ID2" >> $LOG; echo "= FIM ===" >> $LOG. Por fim, dê permissão de execução com chmod +x teste_crud.sh e rode com ./teste_crud.sh para gerar o log.
